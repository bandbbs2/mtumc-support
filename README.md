# MTUMC — Mount Tabor UMC iOS App

A simple hub app for Mount Tabor United Methodist Church (Winston-Salem, NC). Gives members quick access to church bulletins, the YouTube channel, the member directory (via Realm), the church calendar, and basic church info — without duplicating any data already managed by the church's existing systems.
